# 叶子的逼

基于 NovelAI Diffusion 4.5 的 AstrBot 绘画插件，内置画师串预设、中文标签转换、失败重试，以及 Dashboard 绘台 WebUI。

### 图片隐写功能

隐写能力基于 [astrbot_plugin_vangonography](https://github.com/shskjw/astrbot_plugin_vangonography)（作者 shskjw）的图片隐写实现，本插件在其 LSB 隐写与加解密思路上做成了出图后自动入载体、原始 PNG 发送和离线提取。

隐写模式开启后，`/nai` 生成的图片会自动隐藏进载体图库的随机载体图中。机器人会发送
一张明确标注的载体预览，再把真正的隐写 PNG 作为原始文件发送。使用 `/nai提取` 可以
从原始文件还原生成图。

**使用流程：**
1. `/nai载体` + 上传一张图片 → 加入载体图库（可多次添加）
2. `/nai隐写 开` → 开启隐写模式（可选 `/nai隐写 开 我的密码` 加密）
3. `/nai 长发女孩` → 生成图写入载体，收到预览图和原始 PNG 文件
4. 引用原始 PNG 文件 + `/nai提取 [密码]` → 还原出原始生成图
5. 文件不方便回传时发送 `/nai提取 最近 [密码]` → 直接读取服务器保留的本人最近原图

- 载体图库目录由配置项 `cover_dir` 指定，留空时用插件数据目录下的 `covers/`
- 隐写模式按用户独立开关，不影响其他人
- QQ 会压缩或重编码普通图片消息，最低位隐写数据会因此永久损坏。**预览图不能提取，
  必须使用机器人发送的原始 PNG 文件**；如果只剩压缩后的普通图片，无法还原已丢失的数据
- v1.6.1 格式包含版本、加密标记、长度和 SHA-256 校验，可分别提示缺少密码、密码错误和图片损坏
- 升级前生成的旧版原始隐写 PNG 仍可提取；密码只显示“已设置”，不会在聊天中回显

**不经过机器人的离线提取：**

```bash
# 未加密
python vangonography_api.py extract "原始隐写文件.png" -o "输出目录"

# 加密，密码在终端中隐藏输入
python vangonography_api.py extract "原始隐写文件.png" -o "输出目录" --ask-password
```

离线命令直接在本机处理文件，不上传图片也不访问网络。该插件使用自定义数据格式，
普通压缩软件或通用隐写软件无法直接代替此命令解析。

执行 `/nai预设` 会按 `0 = 无预设 [none]`、
`1 = 冰蓝柔光（日系） [iceblue]` 的格式显示编号。
单独发送 `/nai 1` 会保存个人选择，之后发送
`/nai 画面描述` 即可绘图；也可以使用 `/nai 1 描述` 一步完成选择和绘图。

## 中文描述

支持直接用中文，无需自己写英文标签：

```
/nai 1
/nai 长发女孩

/nai 2 白发少女
/nai 3 夜景旗袍
```

支持中英标签混写，例如 `/nai 1girl, 长发, blue eyes`。插件只转换中文部分，
`1girl` 和 `blue eyes` 等已有英文标签会原样保留。只发角色名也可以：插件先使用
内置高频角色词典；未命中时查询大陆可访问的 Bangumi 中文角色库，综合简体译名、别名、
昵称和拼音相似度确认身份，再用英文名或罗马字校准 Danbooru 角色标签。例如大陆用户把
“可玛莉”写成“可玛丽”，也能识别为 `terakomari gandezblood`。

只有第一候选达到高置信且明显领先时才会自动采用。像裸名“玛丽”这类多个作品都存在的
同名角色，插件不会盲猜，需要按以下规范补充作品名：

```text
/nai 角色名@作品名
/nai 玛丽@碧蓝档案
/nai 玛丽@碧蓝档案，蓝发，微笑
```

`@` 是标准分隔符。角色限定后的其他画面描述必须放在作品名后，并用中文或英文逗号分隔。
同时兼容 `/nai 玛丽（碧蓝档案）`、`/nai 玛丽(碧蓝档案)`、
`/nai 碧蓝档案的玛丽` 和 `/nai 玛丽 碧蓝档案`，但建议统一使用 `@`，边界最明确。

如果词典和 LLM 都无法把纯中文描述转换为有效标签，插件会在调用绘图 API 前停止，
明确提示改用英文标签或开启中文智能翻译，不会用无效中文白白消耗一次生成额度。

个人选择保留到插件重载；插件重载后恢复管理面板设置的默认预设。

## 无预设与个人画师

发送 `/nai 0` 可选择无预设模式，也可用 `/nai 0 画面描述` 直接出图。此模式不会追加
任何内置预设画师、画风或自动脸型，只保留 NAI4.5 年份与质量词、个人画师串、用户描述、
通用负面词和当前 NSFW 设置。管理面板也可把 `default_preset` 设为 `none`。

个人画师串可与 0～9 任意模式叠加。使用 `/nai画师 添加 <画师串>` 追加，`设置` 替换，
`状态` 查看带编号的列表，`删除 <编号>` 删除单项，`清空` 删除全部。单个英文画师名可
直接发送，例如 `/nai画师 wlop` 会保存为 `artist:wlop`；多个标签请用逗号分隔。

只接受 `artist:` 标签或单个英文画师名，支持 `{artist:wlop}`、
`1.2::artist:wlop::` 等 NAI 权重写法。数值权重必须大于 0 且不超过 1.5，括号必须配对，
每位用户最多保存 12 个并自动去重。个人画师串只对当前用户生效，插件重载后清空。

## NSFW 开关

发送 `/nainsfw 开` 后，仅当前用户的绘图不再追加内置 NSFW 压制词。该设置不会影响
其他用户，也不会修改管理面板配置。使用 `/nainsfw 关` 可强制关闭，使用
`/nainsfw 默认` 可恢复管理面板中的 `allow_nsfw` 设置。

个人 NSFW 设置保留到插件重载。

## 自动脸型开关

默认开启自动脸型：同一用户连续使用同一预设时，插件会轮换五官与脸型变体，并把
其他变体特征写入排他负面词。发送 `/nai脸型 关` 后，仅当前用户停止注入这些额外
五官、脸型正面词和排他负面词，预设基础负面词中的脸部约束也会删除；预设画风、
非脸部负面词与画师主力轮换仍然保留。

使用 `/nai脸型 开` 可重新开启，`/nai脸型 状态` 可查看实际状态，`/nai脸型 默认`
恢复管理面板中的 `enable_face_variation` 设置。个人设置保留到插件重载。

## 生成反馈

绘图指令通过参数检查后，机器人会立即回复“指令已生效，正在生成”，并显示本次实际
使用的预设、尺寸、NSFW、自动脸型和个人画师数量。参数回退、未识别中文或智能翻译结果会继续
发送一条 `[提示]`；生成完成后再发送图片，生成失败时会发送具体原因。

转换分三层：先按从左到右最长匹配查内置词典（常用描述和高频角色），口语虚词和量词
会被丢掉。词典没覆盖的短角色名先查大陆可访问的 Bangumi，使用中文名、别名、昵称与拼音
相似度进行高置信消歧，再以英文名或罗马字校准 Danbooru 标签；只有第一候选明显领先时才
自动采用。同名歧义会明确提示使用 `/nai 角色名@作品名`；限定解析在普通词典之前执行，
因此作品名不会被“蓝”等颜色词拆开。仍剩有画面意义的中文时，才把整句交给 AstrBot 的
LLM，并与前两层结果合并。中文成功转成标签后，聊天里会继续发送 `[提示] 已智能翻译`。

Bangumi、Danbooru 或 LLM 不可用时自动降级，不阻断出图；只要仍有可用标签就继续生成。
关闭 `llm_translate` 可完全禁用 LLM 调用，但不影响词典和 Bangumi 查询。

英文输入直接透传，不经过任何转换。

## 脸型轮换

自动脸型开启时，同一用户使用同一预设会遍历“画师组合 × 正面画风 × 五官”的完整组合；
一个周期结束后再循环。普通出图不会自动注入构图场景，只有 `/nai随机` 才会使用完整场景法典。

**画师与正面画风轮换。** 冰蓝柔光锁定用户确认的单一画师组合；第二批 6～9 号也锁定
各自真实样图使用的原配方，避免引入未实测画师导致视觉漂移。每组轮换三个同方向渲染
和四组五官。2～5 号继续使用 3～4 个清洗后的画师变体和 3 个渲染变体。来源条目与
法典版本保存在 `source` 字段。法典原始串里的质量词、年份、主体、构图、NSFW、
负面标签和超限权重均已删除。

**五官变体轮换。** 每个预设配 4 组五官特征，逐次按组合顺序取一组，
同时把其余变体的特征写入负面词。单靠正面词拉不开脸型差距，实测必须双向施压：
锐利档配 `tsurime + sharp jawline`，负面压 `round eyes, soft jawline`；
柔和档反过来。

想固定脸型就在描述里自己写五官，命中 `eyes` / `jawline` / `lipstick` /
`cheekbone` / `nose` / `tsurime` / `tareme` 等词时插件不再注入变体，
避免和你的描述对撞。

完全不需要插件追加脸型要求时，发送 `/nai脸型 关`。此时画师主导权仍会轮换，
但上述五官变体、排他负面词及预设内置脸部约束都不会进入请求。

## 尺寸

支持中文别名 `竖图` / `方图` / `横图` / `大图`，或直接写 `832x1216`。

宽高须为 64 的倍数，超出范围或非法值会回退到默认尺寸，不会向上游发送无效请求。

## 绘台 WebUI

插件在 AstrBot Dashboard 的插件详情页提供「绘台」页面，用于浏览器出图、查看最近成图、管理隐写载体和拆封原始 PNG。页面走官方 Plugin Pages：静态文件在 `pages/studio/`，后端接口由 `webui.py` 注册，出图仍复用聊天同一条 `_produce_image` 链路。

打开方式：WebUI → 插件 → 叶子的逼 → 绘台。

页面能力：

- 选择 0～9 号预设、竖/方/横/大图，填写中文或英文描述后出图
- 从 20 条精选单人场景注入示例灵感；从实测画师配方抽取随机画师串
- 展开「NAI 详细参数」配置步数、CFG、CFG Rescale、种子、采样器、噪声调度、质量增强和 SMEA
- 单次追加负面提示词；这些参数仅作用于本次绘台任务，不会改写插件全局配置
- 开关 NSFW、自动脸型、个人画师串和隐写入载体
- 查看最近成图并下载 PNG
- 上传/删除载体图，从原始隐写 PNG 拆出生成图

API 地址和密钥仍在管理面板的 `_conf_schema.json` 中填写，绘台不重复做密钥表单。

## 配置

在管理面板填写：

- `api_base` — OpenAI 兼容端点前缀，不含 `/v1/images/generations`
- `api_key` — 访问令牌，必填
- `model` — 默认 `nai-diffusion-4-5-full`
- `default_size` / `default_preset` — 缺省参数；`default_preset` 设为 `none` 时默认不用预设
- `cooldown` — 用户冷却秒数，0 为不限
- `max_concurrent` — 并发上限，防止打满上游配额
- `allow_nsfw` — 个人未执行 `/nainsfw` 时使用的默认值；关闭时加入 NSFW 压制标签
- `enable_face_variation` — 个人未执行 `/nai脸型` 时使用的自动脸型默认值
- `timeout` — 单次请求超时秒数，范围 1~600
- `retries` / `retry_backoff` — 临时网络故障的尝试次数与指数退避基数
- `keep_images` — 关闭时只保留最近 20 张出图，开启后不自动清理
- `extra_negative` — 追加到内置负面词之后
- `llm_translate` — 是否使用 AstrBot LLM 补充翻译词典未覆盖的中文

## 提示词约定

新增预设时需遵守以下约束，否则出图质量不可控：

**质量词必须用 NAI4.5 体系。** `amazing quality, very aesthetic, absurdres` 有效，
NAI3/SD 的 `masterpiece, best quality` 在 4.5 上不起作用。

**数值权重不得超过 1.5。** `1.2::tag::` 可用，`2.0::tag::` 会推崩去噪过程直接产出纯噪点。
法典里的 `3::artist:xxx::` 是配合特定采样器和步数的，裸用会炸。

**负面词的重点是完成度而非「丑」。** `very displeasing` 和 `bad quality` 是 NAI 自带的
美学评分标签，对成品率影响最大；`sketch` / `unfinished` / `washed out` 压制未画完的线稿感。

**风格词避免语义冲突。** `thick brushstrokes` 与 `soft blended shading` 并存会互相抵消，
多层花括号只会放大冲突。

**平涂系画师与精细渲染互斥。** modare、mignon、kukka 这类画师本身是低对比风格，
只适合明确的平涂类预设；不能与写实厚涂要求混用。

**`positive_variants` 字段只写画风与渲染。** 五官、表情、姿势、构图、视角一律不准
写进去。画师单独放 `artist_variants`，负面压制单独放 `negative`；构图场景只由
`/nai随机` 或绘台“示例灵感”显式注入。

## 测试

```bash
python test_main.py

python test_composition_presets.py
python test_nai_api.py

```

`test_main.py` 覆盖命令参数、0 号无预设、个人预设、个人画师串增删改查、个人 NSFW、
个人自动脸型、隐写文件传输、最近提取、冷却、即时反馈、越界编号和转换失败恢复。
`test_presets.py` 覆盖预设名解析、1～9 编号契约、
尺寸边界、无预设提示词、个人画师串清洗、自动脸型关闭、负面词冲突剔除、权重安全性
与风格词冲突检查。`test_composition_presets.py` 覆盖 64 条独立随机场景、来源 ID、
完整场景串和安全权重。

`test_translator.py` 覆盖中文检测、词典长词优先与去重、虚词剥离、残留识别、
中英混写保留、Bangumi 角色短名查询、词典与 LLM 合并、已智能翻译提示、LLM 输出清洗
与故障降级路径。`test_nai_api.py` 覆盖 Base64、URL 图片、重试、超时与错误响应。
`test_vangonography_api.py` 覆盖 v2 加密与无加密往返、密码错误、SHA-256 完整性校验、
平台重编码破坏、旧格式兼容、容量扩展和离线命令。`test_webui.py` 覆盖绘台路由注册、启动数据、
出图校验、路径穿越、中文载体名、隐写拆封和页面文件契约。全部网络和 LLM 行为均用桩对象模拟，
不产生真实请求。
